## Project Summary

This repository documents the completion of the KNearestNeighbors_Workshop, including hands-on work with the K-Nearest Neighbors (KNN) workflow and its core concepts. The workshop challenge was implemented in `KNN_Workshop_Solution.ipynb`, applying the techniques practiced during the workshop. The submission also includes observations from the Pair Programming Exercise, reflecting on the collaborative process and what was learned. Together, the notebooks and observations demonstrate the student's practical engagement with the workshop material.

## Setup and How to Run

1. (Optional) Create and activate a virtual environment.
2. Install the required packages from the repository root:
   ```bash
   python -m pip install -r requirements.txt
   ```
3. Start Jupyter:
   ```bash
   jupyter lab
   ```
4. Open `KNearestNeighbors_Workshop.ipynb` or `KNN_Workshop_Solution.ipynb` and run the cells in order. All code for the workshop and challenge is runnable directly in the notebooks.
